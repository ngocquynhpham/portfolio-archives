## Chạy local

Checkout nhánh cần xem, rồi:

```bash
git checkout ver-2026   # hoặc ver-2025 / ver-2024
npm install
npm run dev
```

## Deploy

Gắn hosting (Vercel, Netlify, GitHub Pages, …) với **branch tương ứng** — mỗi năm một deployment riêng nếu cần.
